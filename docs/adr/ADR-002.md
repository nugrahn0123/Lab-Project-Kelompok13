# ADR-002: Kontrak API dibekukan di v2.0.0

## Konteks

Mobile dibangun di atas kontrak `openapi-final.yaml`. Perubahan nama medan, penghapusan endpoint, atau perubahan tipe data merusak aplikasi Mobile diam-diam — tidak ada error kompilasi, hanya crash saat runtime. Base URL dan angka batas laju di kontrak harus sama persis dengan yang diuji Scalable agar Mobile tidak membanjiri endpoint.

## Keputusan

Naikkan versi ke `2.0.0` dan tutup semua perubahan yang merusak. Hanya perubahan aditif yang diizinkan setelah ini:

| Perubahan | Boleh? |
|---|---|
| Menambah endpoint baru | ✅ |
| Menambah medan opsional pada respons | ✅ |
| Mengganti nama medan | ❌ |
| Menghapus endpoint / medan | ❌ |
| Mengubah tipe (string → integer) | ❌ |

## Konsekuensi

- (+) Mobile membangun tenang; bentuk kontrak selesai sebelum kode aplikasi ditulis.
- (+) Ketidaksepakatan bentuk diselesaikan sebelum coding, bukan saat demo.
- (-) Kebutuhan baru harus dijawab secara aditif; kadang terasa tidak rapi.
- (-) Perubahan breaking harus menunggu v3.0.0 dan koordinasi penuh tim.
