# ADR-001: Semua endpoint daftar wajib paginasi page/limit

## Konteks

Aplikasi mobile memuat daftar konser di jaringan lambat. Mengembalikan seluruh baris membuat respons besar, boros kuota, dan tidak punya ukuran tetap untuk diuji beban di lapisan Scalable.

## Keputusan

Setiap endpoint daftar menerima `page` (mulai 1) dan `limit` (default 20, maksimum 100), lalu membalas amplop:

```json
{ "data": [...], "page": 1, "limit": 20, "total": 137 }
```

## Konsekuensi

- (+) Respons kecil dan dapat diprediksi; mobile dapat memuat bertahap.
- (+) Uji beban punya ukuran halaman tetap sebagai dasar perbandingan.
- (-) Klien harus menyusun ulang data antar halaman.
- (-) `total` menuntut satu query COUNT tambahan tiap permintaan.
